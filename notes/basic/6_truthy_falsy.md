# Truthy Value and Falsy Value

| Category        | Falsy Value         |
|:----------------|:--------------------|
| Constants       | `None` `False`      |
| Numeric Zeros   | `0` `0.0` `0j`      |
| Empty Sequences | `''` `""` `[]` `()` |

အပေါ်က table က falsy value တွေဖြစ်တယ်။ falsy value ထဲမှာမပါတာတွေက truthy value တွေဖြစ်တယ်။
ဥပမာ `s` `-10` ` ` (space) စတဲ့ပုံစံလိုမျိုးတွေက truthy value တွေဖြစ်တယ်။
