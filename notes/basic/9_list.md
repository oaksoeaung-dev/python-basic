# List

Data type အမျိုးမျိုးကို စုစည်းသိမ်းထားနိုင်တဲ့ data structure ဖြစ်တယ်။ `List` ထဲမှာ ဘယ် data type မဆိုထည့်လို့ရတယ်။

`List` ထဲထည့်လိုက်တဲ့ data တိုင်းက ထည့်လိုက်တဲ့ order အတိုင်းရှိနေမှာဖြစ်တယ်။

`List` ထဲက data တွေကို ပြင်တာပဲဖြစ်ဖြစ် ဖျက်တာပဲဖြစ်ဖြစ် ထပ်တိုးတာပဲဖြစ်ဖြစ် လုပ်လို့ရတယ်။ Mutable ဖြစ်တယ်။

Duplicate value တွေလည်းထည့်လို့ရတယ်။

`List` ထဲက data တွေကို ထုတ်ကြည့်ချင်ရင် `[index]` နဲ့ထုတ်ကြည့်လို့ရတယ်။ index က `0` က စတယ်။

```python
my_list = ["Toyota", 10, False, 20, {"name": "Aung"}]

print(my_list[0])
print(my_list[len(my_list) - 1])
```
